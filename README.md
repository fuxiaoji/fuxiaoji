## About

我是傅文基，西南财经大学金融学本科在读。我的主线兴趣是把 **AI Agent、全栈工程、数据工程和可交互系统** 做成真正能跑起来的产品。

最近重点在做：

- **AI 应用开发**：RAG、工具调用、MCP、多 Agent 协作、Prompt 工程和 LLM API 集成。
- **游戏 AI / 仿真系统**：用 C++ 做高性能状态机与训练环境，用 TypeScript 做前端可视化，用 PyTorch 做模型迭代。
- **数据工程与自动化**：面向复杂网页结构的定向爬虫、异步并发采集、增量更新、结构化导出与可视化分析。
- **金融科技交叉**：因子模型复现、宏观/市场数据处理、量化建模与实证分析。

## Featured Projects

### [bismarck hunt / wargame](https://github.com/fuxiaoji/wargame)

基于 C++ / TypeScript / PyTorch 的兵棋游戏 AI 演化框架。项目先完成《追击俾斯麦》电子化，再把训练环境和前端渲染解耦，用于动态博弈场景下的智能体训练。

- C++ 构建高性能状态机与演化环境，支撑高并发对局和样本采集。
- TypeScript + Canvas 搭建可视化引擎，用于展示对局、训练数据和 AI 行为。
- 基于 PyTorch 落地 Transformer / LSTM 序列状态建模与遗传演化强化学习链路。
- 产出 200+ 不同难度与战术风格的 AI 模型，核心 AI 在基线对战中胜率提升约 40%。

### [VibePad](https://github.com/fuxiaoji/VibePad)

面向 Vibe Coding 和日常效率场景的手柄键鼠模拟器。把物理手柄输入映射为系统级鼠标移动、键盘快捷键和组合宏，支持 YAML 配置。

- Python 实现输入监听、系统级事件派发与可配置映射。
- 适合代码编辑、演示、轻量远程控制和自定义工作流。
- 目前是我 star 数最高的开源项目。

### [AI 实时听课助手](https://github.com/fuxiaoji/ai-class-assistant)

基于音频流处理和大语言模型意图识别的课堂助手。它监听实时语音，识别提问场景，并结合本地课件生成增强参考答案。

- TypeScript 项目，面向真实课堂和学习场景设计。
- 结合实时音频、LLM 推理和本地资料检索，探索更自然的学习辅助工作流。

### [tieba_spider](https://github.com/fuxiaoji/tieba_spider)

百度贴吧全量数据抓取工具，支持楼层、楼中楼和图片资源并发下载，内置基础防封与结构化导出能力。

- Python 异步并发抓取复杂嵌套 Web 结构。
- 面向长帖、多媒体资源和批量归档场景优化。

### [crawler_for_biddingprofile](https://github.com/fuxiaoji/crawler_for_biddingprofile)

重庆公共资源交易网中标结果定向爬虫，实现历史数据采集、自动分页、增量更新和 CSV / Excel 导出。

- 从政务网站抓取招投标历史数据并完成结构化清洗。
- 用自动化脚本替代重复检索，为后续数据分析提供稳定输入。

### [reprodue_fama_modle](https://github.com/fuxiaoji/reprodue_fama_modle)

Fama-French 三因子模型复现与实证分析项目，覆盖底层数据提取、收益率测算、回归检验和可视化。

- 长周期因子数据处理与学术式分析流程。
- 展示我在金融建模、数据清洗和 Python Notebook 表达上的基础能力。
